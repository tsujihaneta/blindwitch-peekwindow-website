## GitHub Pages に公開する場合

1. このディレクトリの内容を新しいリポジトリのルートにコピーし、内容と権利、各ストアリンクを確認します。Unity プロジェクト全体を公開しないよう注意してください。
2. 所有者が GitHub にリポジトリを作成し、ファイルをコミット・プッシュします。
3. リポジトリの Settings → Pages → Build and deployment で、ブランチからの公開を選び、対象ブランチと `/ (root)` を指定して保存します。
4. 表示された URL で全ページ・画像・動画・リンクを確認します。パスは相対指定のため、`/<repository>/` 配下でも使えます。公開先 URL 確定後、バナー用 HTML や OGP URL の追加を検討してください。
